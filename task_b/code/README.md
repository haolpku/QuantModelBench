# Task B runtime

Run the scripts from the repository root. See the [Task B guide](../README.md)
for the frozen-code pipeline. `factoropt/` contains the implementation,
`schemas/` the response contracts, and `scripts/` the builders and runners.
`requirements.txt` includes the repository-wide dependency requirements.
The shared agent/tool loop is in [shared/agentic/](../../shared/agentic/).
