# Task C runtime

Run the scripts from the repository root. See the [Task C guide](../README.md)
for codegen and rolling commands. `factoropt/` contains data handling, candidate
execution, rolling orchestration and portfolio accounting; `schemas/` contains
the response contracts. `requirements.txt` includes the repository-wide dependency
requirements. The shared loop is in [shared/agentic/](../../shared/agentic/).
